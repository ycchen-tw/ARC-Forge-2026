The game is reached through ./act, and ./act is the whole interface: the server
behind it offers nothing else to find -- no rules, hints, docs or source -- and an
action you send it any other way is still counted against this game. Do not probe
its endpoints or write your own client for it.

Do not go looking for the game's implementation, a solution or a walkthrough. It
is not reachable from here, and the search spends the budget you need to play.

This workspace, its token and its game are yours. Other games run on this machine
as other users; their processes and files are not yours to look at or touch.

Memory and disk are shared with every other game here, and running out ends
games, possibly all of them. Stay within the memory limits in AGENTS.md, keep
what you write to disk small (do not save every state you explore), and write
only inside your workspace -- not /tmp, not /dev/shm.
